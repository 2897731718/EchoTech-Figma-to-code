---
description: 根据 Figma 链接提取前端骨架并结合当前项目完成页面实现
argument-hint: <figma-url> [--framework=vue|react|html]
---

请根据用户提供的 Figma URL 实现页面或组件。

执行顺序：

1. 阅读当前项目中相邻页面、公共组件、样式方案和路由约定。
2. 根据目标技术栈运行：

   ```bash
   figma-to-code "$ARGUMENTS"
   ```

3. 把 CLI 输出作为结构骨架，结合项目已有组件、token 和代码风格整理成可维护实现。
4. 补齐设计稿无法表达但项目要求的交互、状态、响应式和可访问性处理。
5. 运行最相关的类型检查、测试和构建。

注意：

- 不要输出或提交 `FIGMA_PAT`。
- 不要盲目覆盖已有文件；修改前先阅读现有实现。
- 优先复用项目组件，不要为追求像素一致复制已有能力。
- 对无法从设计稿确认的行为明确说明假设。
